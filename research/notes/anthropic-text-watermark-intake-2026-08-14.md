## 2. Change from the 2026-08-13 intake

The 2026-08-13 intake correctly recorded that Anthropic had not identified the
text-watermark mechanism. That statement is now historical. The new technical
article identifies the mechanism family, so the Anthropic slot is no longer
completely undocumented at that level. No provider detector became available.

## 3. Mechanism-family disclosure

Anthropic states that Claude's text watermark is "a version of the SynthID-Text
approach" published by Google DeepMind. This is provider authority for the
family relationship. It is not a specification of Anthropic's deployed
configuration and is not a claim that the public DeepMind repository reproduces
Claude.

## 4. Text and hidden-character boundary

Anthropic says nothing is appended to the text and there are no hidden
characters. The described watermark acts through model token choices. This does
not make Unicode evidence irrelevant: Unicode property observations remain
independent evidence, and C2PA remains a separate signed-file provenance
mechanism.

## 5. Provider key

Anthropic says detection uses its key. The key is private and not public.
WaterLARP's deterministic SynthID research keys are not Anthropic keys and do
not acquire provider authority from the family disclosure.

## 6. Detector and API state

Anthropic says it will offer a watermark detection API "soon" and that it is
still working out implementation details. The API is therefore announced or
forthcoming, not available. Its request/response contract, prerequisites,
statistic, threshold, error semantics, calibration, and false-positive target
remain unknown.

## 7. Provider-reported claims to test

The following are vendor-reported claims, not replicated or measured WaterLARP
results:

- shorter samples provide less detection information (`evidence-length`);
- factual or otherwise low-choice text offers less watermarking opportunity
  (`base-entropy`, `task-domain`);
- proofreading or light editing may leave too little Claude-selected text
  (`mixed-authorship`, `marked-fraction`, `transformations`);
- more Claude-authored text provides more opportunity for signal
  (`evidence-length`, `marked-fraction`);
- exact-choice code generally carries less signal, while comments may offer
  choices (`code`, `base-entropy`, `task-domain`);
- Claude-produced translations are watermarked (`translation`);
- light edits may preserve some signal while a complete rewrite can remove it
  (`transformations`, `quality-integrity`);
- Anthropic reports no practical quality impact in internal testing
  (`quality-integrity`).

The Help Center separately warns that translating an already marked passage can
make its mark undetectable. That does not conflict with the technical article's
claim about a new translation generated by Claude: these are different
operations.

## 8. Exact unknowns

Anthropic does not disclose Claude's research/production key material,

sampling table, detector family, detector statistic, threshold, false-positive
target, repetition-mask behavior, exact model coverage, or exact public
reference configuration. No WaterLARP KGW or SynthID setting is inferred to be
an Anthropic setting.
