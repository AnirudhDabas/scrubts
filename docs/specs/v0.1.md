# v0.1 specification

## Goal

Provide an evidence-first local CLI that can inspect supported artifacts for
standards-backed Unicode observations and C2PA provenance, plus a separate
controlled research harness for reproducible public watermark baselines.

## CLI

### `scrub inspect <path>`

- Initial implementation may begin with single-file behavior; recursive directory
  support lands only after single-file semantics are stable.
- Default output is human-readable.
- `--json` emits only versioned report JSON on stdout.
- Diagnostics/errors go to stderr.
- Inspection never modifies the input artifact.

### `scrub doctor`

Not required in the first implementation milestone. When added, diagnoses local
support/dependencies and does not modify the environment without explicit action.

## v0.1 supported mechanism families

- UTF-8/Unicode forensic observations defined by approved Unicode specs/ADRs.
- C2PA inspection/validation for formats supported by the pinned official SDK.
- Controlled WaterLARP baseline experiments for selected public schemes.

## Non-goals

- arbitrary AI authorship detection;
- universal watermark removal;
- statistical detection without required scheme/detector prerequisites;
- Claude text-watermark detection before a supported detector exists;
- automatic rewriting/paraphrasing;
- hosted service;
- web UI;
- speculative plugin framework;
- telemetry.

## Acceptance criteria

- deterministic, versioned report schema;
- adversarial fixtures for every shipped scanner;
- machine-readable output suitable for automation;
- all shipped checks pass with `just check`;
- limitations documented beside capabilities;
- source/license ledger updated for every relied-on implementation.
